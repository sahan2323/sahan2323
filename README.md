## Projects

### `oneCoreLab` — Startup Platform & Client Dashboard

> Full-stack TypeScript application on Next.js, with the React frontend and server-side API routes in a single typed codebase. Authenticated client portal handling registration, login, and session-controlled dashboard access, plus a task management system with full CRUD over PostgreSQL through Prisma — schema design, migrations, and typed queries. Analytics views render project status and activity data as internal tooling for the agency.

`TypeScript` `Next.js` `React` `PostgreSQL` `Prisma` `Tailwind CSS`

**Focus:** Authentication & Sessions · ORM & Schema Design · CRUD Dashboards · SSR & Code Splitting

**[Live →](https://onecorelab-website.vercel.app/)** · **[Repository →](#)**

### `Jayaka Ceylon Cinnamon` — Freelance Client Website

> A production site for a Ceylon cinnamon exporter, built working directly with the client from requirements through launch. The centerpiece is a scroll-driven animation system using the Canvas API and Framer Motion — frame-by-frame playback tied to scroll position for a cinematic product showcase — on top of a reusable component library and shared design system.

`Next.js` `React` `Canvas API` `Framer Motion` `MongoDB` `Tailwind CSS`

**Focus:** Scroll-Driven Animation · Design Systems · Component Architecture · Client Delivery

**[Live →](https://jayakawebnew.vercel.app/)** · **[Repository →](#)**

---

### `Track My Habits` — Full-Stack Web Application

> A habit tracking application with user registration, authentication, session management, and full CRUD over user-owned records. The Express backend uses RESTful routing with separated route and controller layers, request validation, and structured error responses; PostgreSQL models persist user and habit data with access logic that isolates records per user.

`Node.js` `Express` `EJS` `PostgreSQL` `Tailwind CSS`

**Focus:** REST API Design · Auth & Sessions · Data Isolation · Server-Side Rendering

**[Live →](https://track-my-habits-web-322.vercel.app)** · **[Repository →](#)**

`React` `Vite` `Tailwind CSS` `Framer Motion` `React Router`

**Focus:** Third-Party API Integration · Responsive Design · Animation · Production Deployment
